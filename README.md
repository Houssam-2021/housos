# HoussamOS

A gaming-ready Linux desktop for everyday users, built on [Bazzite](https://bazzite.gg)
(Fedora Atomic + KDE Plasma) using the Universal Blue image template.

## How it is built

- `Containerfile` + `build_files/build.sh` define the OS image.
- GitHub Actions (`build.yml`) builds it every day and on every push, and publishes it to
  `ghcr.io/houssam-2021/houssamos`.
- `build-disk.yml` (run manually from the Actions tab) turns the image into an installable ISO.
- Installed systems update themselves from that image and can roll back to the previous version.

## Branding

Houssam's art is in `branding/src/` (boot animation video and logo). The wallpapers are generated by
`branding/make_wallpapers.py`, the glass Plasma theme and colour schemes by `branding/make_theme.py`
(all colours in one palette there). After changing any of it, run those and
`python branding/make_branding.py --preview` (needs Pillow, numpy and ffmpeg), then commit the
regenerated files in `system_files/`. `build_files/build.sh` installs them and rebuilds the initramfs
so the boot animation is included.

The Liquid Glass icon theme comes from `branding/src/HoussamOS-LiquidGlass.zip`. To bring in a new
version, run `python branding/import_icons.py path/to/the.zip`: it checks every icon and re-applies
the fixes listed in the script.

## Roadmap

1. Base image with HoussamOS branding
2. Visual identity: logo, boot animation, login screen, glass dock and top bar
3. Undo timeline (snapshots before every change)
4. Gaming extras: "Will my games work?" checker, automatic game mode
5. Privacy report
6. Offline AI assistant
7. Guest mode

## Image signing

Signing is skipped until a `SIGNING_SECRET` repository secret exists. See the
[Universal Blue template docs](https://github.com/ublue-os/image-template#container-signing).
